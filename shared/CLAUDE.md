# `shared/` — общее для всех

Три модуля, и все здесь по одной причине: у них больше двух потребителей и нельзя, чтобы
кто-то из них зависел от ядра. Общие правила репозитория — в [корне канона](../CLAUDE.md).

| Модуль                 | Что это                                                                      |
| ---------------------- | ---------------------------------------------------------------------------- |
| `side-effect-guard.ts` | предохранитель побочек в тестах и общий журнал попыток                       |
| `ralph-util.ts`        | чистые утилиты без побочек: экранирование для шелла, числа, sleep, отказ git |
| `project-traces.ts`    | общий скан проектных следов в дереве, сообщениях коммитов и описаниях PR     |

## Местные правила

**Порог для переезда сюда — третий потребитель.** До него дубль дешевле связности. После —
дороже: копии расходятся молча, правку вносят в одну, а красным становится другая.

**Здесь не может быть импорта из `core/`.** Модули нужны потребителям, которые сами
импортируются ядром; обратная стрелка даёт цикл. Именно из-за него предохранитель когда-то
и жил в двух копиях с двумя журналами.

**Побочек нет вовсе.** `ralph-util.ts` и `project-traces.ts` — чистые преобразования вход→выход.
Функция, которой понадобился диск, шелл или сеть, в этот модуль не переезжает: её место рядом с
тем, кто ей владеет.

## Как работает предохранитель

Под `RALPH_NO_SIDE_EFFECTS=1` боевая побочка не исполняется, а **записывается в журнал** и
бросает. Журнал нужен отдельно от throw потому, что половина боевых вызовов обёрнута в
`try/catch` — одного исключения для покраснения теста не хватает. Журнал сверяет общий
`afterEach` в `tests/test-setup.ts`.

Тест, который зовёт побочку НАМЕРЕННО (проверяет сам предохранитель), обязан забрать записи
из журнала сам — иначе общий `afterEach` уронит его же.
