# Git Commit

Закоммить текущие изменения.

## Порядок действий

1. `git status --short` и `git diff --stat` — что изменилось (полный дифф без нужды не читай).
2. Сгруппируй связанные изменения. Несвязанные — РАЗНЫЕ коммиты.
3. `git add` только нужных файлов, не `git add .` вслепую.
4. **Сообщение — в файл, проверка командой, и только потом коммит:**
    ```bash
    M=$(mktemp "${TMPDIR:-/tmp}/commit-msg.XXXXXX")
    printf '%s\n' 'type(scope): заголовок' '' '- деталь' > "$M"
    node commit-msg.mts "$M" && git commit -F "$M"
    git log --oneline -1
    ```
    Это не ритуал. Потолок заголовка — 72 символа, а кириллица длинная: 72 символа — это
    8–9 слов вместе с типом и областью, и на глаз это не прикинуть. Считает команда, не
    автор. `git commit -m` с заголовком по памяти — запрещённая форма.

    Та же команда сканирует сообщение на проектные следы (путь машины, адрес хоста, имена
    из `RALPH_TRACE_DENY`) **до** коммита. История канона публичная: след в сообщении,
    уехавший в `origin`, правкой файла уже не убрать — скан истории
    (`tests/project-traces.test.ts`) найдёт его, когда исправлять будет нечем.

## Формат сообщения

```
type(scope): краткое описание в повелительном наклонении

- деталь (только если нужна)
```

- **type**: `feat` / `fix` / `refactor` / `test` / `docs` / `chore` / `perf` / `ci` / `style`.
- **scope** — каталог или область: `core`, `adapters`, `runtime`, `shared`, `provision`,
  `guard`, `stand`, `launcher`, `docs`… Только строчные латинские буквы, цифры и дефис.
- Заголовок — до 72 символов, без точки в конце. Язык описания — русский, тип и область —
  английские.
- Номер карточки в заголовке — только реальной карточки этой площадки (`(#186)`): площадка
  связывает PR с карточкой по любому `#N` в тексте, включая сообщения коммитов.

## Правила

- **В `main` не коммить и не пушь.** Коммит — в ветку `feature/…`, `fix/…`, `chore/…`, дальше
  PR. Оказался на `main` — сначала ветка, потом коммит.
- Не коммить `ralph.config.json`, `ralph.project.md` потребителя (кроме
  `.claude/ralph/ralph.project.md` канона), `.claude/local/`, env-файлы, токены, артефакты
  сборки.
- Хук упал — исправь причину и повтори. `--no-verify` не используй никогда.
- Подпись соавтора — как просит среда сессии; рекламных подписей не добавляй.
