## Сделано

**Милестоун «R0 · Фаза 1: канон и его гейт» закрыт.** Гейт зелёный на чистом клоне
(`npm ci && npm run gate`, 37 файлов), скан следов идёт и по дереву, и по сообщениям
коммитов, чистота ядра сверяется сплошным сканом с храповиком долга `DEBT`. Политика веток,
ревью и CI лежат в `.sourcecraft/`; SessionStart-хук поднимает handoff и состояние git.

**Доки — одна пара на папку, источник один.** До этого `CLAUDE.md` был заглушкой-адресом:
экономил копию ценой того, что половина агентов правил не читала вовсе — переход по ссылке
моделью не гарантирован. Теперь правила лежат в `CLAUDE.md`, а `AGENTS.md` рядом
**генерируется** из него (`docs-sync.mts`, `npm run docs:sync`): единственное
преобразование — цель относительной ссылки переезжает на второе имя, поэтому подпись ссылки
пишут без имени файла. Расхождение невозможно механически, а не по договорённости:

- пересборку после правки делает PostToolUse-хук `.claude/hooks/sync-docs.cjs`;
- барьером хук НЕ является (правка руками, другим инструментом и из CI идёт мимо) —
  равенство сверяет `tests/docs-coverage.test.ts` в составе гейта, от противного:
  подсунутая правка копии, отсутствующая копия, внешняя ссылка с тем же именем.

Заодно поправлено враньё в правилах: раздел Git всё ещё говорил «ветка `main`», хотя прямой
push в неё уже запрещён политикой.
