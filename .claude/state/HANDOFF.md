## Сделано — milestone «R0 · Фаза 1: канон и его гейт»

**#1 Гейт.** Было 13 красных файлов из 36, стало 0 из 37. Проверено экспортом индекса в
отдельный каталог: `npm ci && npm run gate` — и больше ничего не нужно. Что чинилось:

- **своего прогона не было вовсе** — тесты гонял vitest потребителя. Заведены свои
  devDependencies и `vitest.config.ts`; с ним приехали `RALPH_NO_SIDE_EFFECTS=1` и общий
  `afterEach`, без которых треть сьюта была зелёной по ложной причине (и однажды написала
  боевой `ralph.log` прямо в дерево);
- **пути от CWD** в четырёх файлах ждали раскладку `.claude/ralph/` у потребителя —
  переведены на `import.meta.dirname`;
- **тест ядра импортировал скрипт потребителя** ради словаря severity. Направление
  развёрнуто: словарь экспортирует ядро (`SEVERITY_LEVELS`), потребитель сверяется у себя.
  Сверка «фикстура не повторяет боевой конфиг» включается `RALPH_REAL_CONFIG`;
- `gate.mts` + npm-скрипты; `ralph.project.md.example` — проектная половина контракта
  принадлежит потребителю, канон везёт шаблон.

**#2 Следы.** Скан идёт частью сьюта; добавлен проход по **сообщениям коммитов** — след в
истории правкой файла не убирается. Обе половины проверены от противного. Пустой
`RALPH_TRACE_DENY` называет вслух гейт: в выводе зелёного теста этого никто не увидел бы.

**#4 Чистота ядра.** Ручной `EXPECTED` из 25 путей заменён набором из `git ls-files` плюс
явная сверка исключений. Белый список «очищенных модулей» в скане команд форжа заменён
сплошным сканом с храповиком долга (`DEBT`, сверяется равенством).
**#3 Доки.** Корневой `AGENTS.md` (+ `CLAUDE.md` ссылкой) и `AGENTS.md` в шести папках. От
дерева не отстают — сторожит `tests/docs-coverage.test.ts`.
