# `.claude/` — оснастка сессий в репозитории канона

Здесь лежит то, что получает сессия Claude Code, открытая в дереве канона: хуки, скиллы,
состояние между сессиями. Ядром это не является: потребитель держит свою `.claude/`, а
ядро приходит к нему каталогом или подмодулем. Общие правила репозитория — в
[корне канона](../CLAUDE.md).

| Путь                            | Что это                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------- |
| `settings.json`                 | проводка хуков: какой зовётся на каком событии и инструменте                 |
| `hooks/guard.cjs`               | PreToolUse-барьер: секреты, деструктивное, MCP вне allowlist, службы хоста   |
| `hooks/guard-rules.cjs`         | правила барьера; `guard.cjs` только грузит их и держит fail-closed           |
| `hooks/guard-shell.cjs`         | политика над вызовами оболочки: удаление, сброс дерева, манифест, адреса     |
| `hooks/shell-calls.cjs`         | разбор команды оболочки в список вызовов (`sh -c`, подстановки, heredoc)     |
| `hooks/guard-host-services.cjs` | systemctl, docker, Caddy — запрещено любое изменение состояния               |
| `hooks/guard-process-kill.cjs`  | `kill` — только свой процесс и только по литеральному pid                    |
| `hooks/guard-wiring.ts`         | сверка проводки: guard подключён и накрывает Bash, файловые инструменты, MCP |
| `hooks/skill-barrier.cjs`       | правка теста в сессии петли — только после вызова `Skill(vitest)`            |
| `hooks/load-context.cjs`        | SessionStart: подгружает `local/HANDOFF.md`                                  |
| `hooks/sync-docs.cjs`           | PostToolUse: пересобирает `AGENTS.md` после правки `CLAUDE.md`               |
| `skills/vitest/`                | скилл vitest (сгенерирован в antfu/skills), правится только регенерацией     |
| `local/HANDOFF.md`              | передача между сессиями; локальный, под `.gitignore`                         |
| `ralph/ralph.project.md`        | проектная половина промпта петли на каноне (конфиг рядом — локальный)        |

## Местные правила

**Барьер держит только код выхода 2.** У PreToolUse код 1, таймаут и «не запустился»
Claude Code считает ошибкой без блокировки, и вызов исполняется. Поэтому любой отказ
самого барьера (не загрузились правила, правило бросило, вход не разобрался) обязан
кончаться двойкой, а не падением процесса. Под `bypassPermissions` `permissions.deny` не
действует вовсе, и упавший хук означал бы открытый канал.

**Работает ли барьер, проверяет раннер, а не тест.** Тест проводки сторожит ТЕКСТ
`settings.json`. Перед первой сессией раннер подаёт хукам заведомо запрещённые вызовы и
безобидный (`core/guard-probe.ts`) и не стартует, если запрещённое прошло или безобидное
не пропущено. Правишь хук — живой кейс `core/guard-probe.test.ts` прогоняет пробу на
настоящих хуках этой папки. Рантайм кодера без Claude-хуков (`openai` — `codex exec`) проба тоже
отвергает: своего барьера у него нет, и сессия пошла бы мимо этой папки целиком.

**Барьер минимальный, и это решение.** От потребителя переехало то, без чего петлю
нельзя пускать на канон ночью. Правила о номерах чужого трекера в тексте для площадки не
переехали: у канона «чужие» — потребители, а их имён в публичном дереве быть не может.
Перечня боевых служб хоста тоже нет — вместо «не трогай эти» здесь «не трогай ничего»
(почему — докблок `guard-host-services.cjs`). Барьер с настройкой под установку — Фаза 11.

**Ряд барьера скиллов едет вместе со скиллом.** Правило, требующее скилл, которого нет в
`skills/`, заблокировало бы правку навсегда: вызвать его нечем. Тест сверяет это сам.

**Хуки — CommonJS без зависимостей.** Они запускаются до `npm ci` и в любом окружении;
типы для тестов — рядом, в `*.d.cts`. Тесты хуков проходят typecheck канона:
`tsconfig.json` включает `.claude/hooks/*.ts` явно, потому что `**` скрытые каталоги
пропускает.
